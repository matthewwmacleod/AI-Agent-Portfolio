# AI-Agent-Portfolio
AI Agent Portfolio for Matt MacLeod

A static portfolio site showcasing AI agent projects, skills, and contact info.

## Running locally

No build step required. Serve the directory with any static file server, e.g.:

```
npx serve .
```

Then open the printed URL in your browser.

## Customizing

- `index.html` — content: About text, project cards, skills, contact email
- `css/style.css` — styling and theme colors (auto light/dark based on system preference)
- `js/main.js` — mobile nav toggle and footer year

Replace the placeholder project cards, skills, and the contact email in `index.html` with your own details.
